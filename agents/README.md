# Agent Guide Index

The root `AGENTS.md` is the authoritative instruction file for this repository. These focused guides expand it without redefining the repository structure.

## Guides

- [`ORGANIZATION.md`](ORGANIZATION.md) — canonical paths, file naming, identity, deduplication, and where information belongs.
- [`RESEARCH.md`](RESEARCH.md) — source discovery, evidence collection, provenance, conflict handling, and research batching.
- [`SCHEMA.md`](SCHEMA.md) — normalized fields for family, model, source, and coverage records.
- [`VALIDATION.md`](VALIDATION.md) — checks required before a research change is considered complete.

## Agent rule

Do not create a new organization convention inside a task. If a new data type does not fit the documented layout or schema, update the governing agent documentation first and migrate consistently.
